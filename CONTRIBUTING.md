# Contributing

Thanks for wanting to help.

## Bug reports

Open an issue with:
- the device (TV box, projector, TV or phone model) and Android version
- the MidnightBeam version and where you installed it from (GitHub, F-Droid)
- what you expected and what happened

Overlays behave differently on some TV boxes, so reports from devices I don't have are especially useful, even when everything works.

## Code

- Plain Java, no Gradle: build with `./build.sh` (see the README).
- Keep changes small and focused, one topic per pull request.
- The settings screen must stay usable with D-pad and OK only.
- No trackers, no analytics, no new network connections.

For bigger changes, open an issue or a discussion first so we can agree on the approach.
